# 公开数据与来源边界

本目录是 2026-11-18 实验的公开展示副本，导出日期 2026-11-23。原始冻结实验与完整交付包独立保留，不因公开导出而修改。

## 保留的数据

- 40 组逐请求 `requests.jsonl`，共 11,560 条，保留唯一请求 ID、到达偏移、发送落后、token、终态、TTFT/E2E 和失败原因。
- 所有正式/验证轨迹、合成 prompt token ID、运行清单、已保存的网关事件与终态。
- 原始结果表、种子内配对效应、图表、技术参数、标定和开发选择。
- 真实取消探针、功能测试 XML、依赖版本快照及最终审计摘要。

数据为合成工作负载计量，不包含业务对话或模型权重。1 次客户端读取失败保留；没有通过删除失败改善成绩。

## 导出变换

设备 UUID 在所有导出文件中一致替换为 `GPU-PUBLIC-DEVICE-0`。内部用户路径、命名空间与节点名替换为通用示例。GPU 别名只保留“同一设备”的配对关系；不是独立公开的设备身份凭证。

原监控约 458 MB，公开版仅保留原采样的时间偏移、网关状态、引擎 running/waiting 与 KV cache 使用率 gauge，删除与本分析无关的大型直方图。这足以复算已发布的突发时间线，但不支持分析被删除的其他 Prometheus 指标。

权重、Python 环境、编译缓存、访问凭据、服务器入口、内部部署回执、原始源码压缩包和完整 provenance 副本不公开。原源码压缩包含当时的生成缓存，不能直接作为干净源码发布。

## 哈希如何解释

`PUBLIC_EXPORT.json` 逐文件记录原件 SHA256、公开副本 SHA256、是否字节不变以及监控缩减说明。未变的请求和轨迹可直接核验原始哈希。

需区分字节哈希与内容哈希：运行清单里的 `trace_sha256` 和 `prompts_sha256` 使用 `json.dumps(value, sort_keys=True)` 后的 JSON 内容计算；公开导出清单对实际文件字节计算 SHA256。二者不能直接混用。

运行清单中 `frozen_config_sha256`、`source_manifest_sha256`、`model_manifest_sha256`、`environment_sha256` 是当时运行引用的原始来源指纹，保留用于对照与配对兼容性检查。经过脱敏的配置不会再匹配原始冻结配置哈希；公开版不声称可以离线认证所有未公开的来源材料。

`PUBLIC_INTEGRITY.json` 为本次最终公开文件的完整性清单，包含新增文档与核验脚本。它保护仓库文件的一致性，不是签名、第三方见证或防伪证明。`scripts/verify_public.py` 先核验公开字节，再重新计算指标。

原 `scripts/verify_delivery.py`、`audit_evidence.py` 等归档工具保留实现供审阅；它们依赖完整的私有交付目录。公开核验使用 `verify_public.py`。报告中提及的安装失败、探针失败归档等历史记录保留在原始交付包，公开目录不包含完整过程日志。
